# Translation Review Notes

The museum provides English, Simplified Chinese, French, Traditional Chinese, Japanese, Russian, German, and Spanish. Each local language pack contains 126 text fields and eight collection records. Interface labels, image descriptions, page titles, dates, places, collection summaries, and translation-retry controls are included.

## Review Basis

English and Simplified Chinese were extracted from the existing humanized museum copy. The six additional translations received an independent agent review for meaning, historical names, dates, quantities, qualifications, and natural museum language. The review corrected two Japanese portrait-related terms and retained original institution names where helpful. This is not certification by professional native-language translators; native curatorial approval remains appropriate before treating the new translations as official museum terminology.

## Curatorial Confirmation

The original English names **University of Nanking**, while the original Simplified Chinese uses **南京大学**. The Traditional Chinese and Japanese translations use **金陵大學 / 金陵大学**, following the historical English institution name. They retain **University of Nanking** in parentheses; German and Russian also retain the English source name alongside their localized rendering.

The museum should confirm the institution named in the Sutton correspondence and reconcile the two original sources. The original English and Simplified Chinese text has not been silently rewritten to decide that question. Localized museum/exhibition names and the China Emergency Relief Committee's name should also receive the museum's preferred terminology approval.

## Verification

Automated checks require complete locale keys, nonempty translated fields, eight records in the same order, and unchanged object IDs, image paths, and display metadata. The original English/Chinese factual checks remain. Browser tests inspect actual translated text and accessible attributes across all six pages and four viewport sizes, including saved language selection and unavailable-translation handling.

An automated pass verifies coverage and behavior, not every nuance of translation. Preserve this distinction when updating the language packs.
